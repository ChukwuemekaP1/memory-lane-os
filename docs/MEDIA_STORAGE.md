# Memory Lane — Media Storage (Neon Object Storage)

Status: **Connected and live-verified on `dev`** (`2026-11-19`).

## 1. Bucket & Endpoint Configuration (`dev`)

- **Driver:** `STORAGE_DRIVER=s3` (`backend/app/services/storage.py`, `S3Storage` with `boto3` S3v4 path-style signing)
- **Endpoint:** `https://br-damp-truth-beh9ifs1.storage.c-9.us-east-2.aws.neon.tech` (`us-east-2`)
- **Bucket:** Private bucket `assets` (`access: private`, provisioned on `dev` per `neon.ts`), mapped to both `S3_BUCKET_ORIGINALS=assets` and `S3_BUCKET_DERIVATIVES=assets`.
- **Privacy:** Unauthenticated direct HTTP GET to `assets` objects is denied (`403 Forbidden`). All browser uploads and downloads use short-lived signed URLs (`15m` PUT, `60m` GET).

## 2. Key Layout & Separation

| Prefix | Contents | Immutability / Retention |
|---|---|---|
| `originals/<space_id>/<asset_id>.<ext>` | Original user/guest uploads (images, videos, audio) | Immutable; never overwritten by processing |
| `derivatives/<space_id>/<asset_id>/<rendition>` | Thumbnails, previews, video posters | Generated by FFmpeg worker; EXIF stripped |
| `generated/<space_id>/<asset_id>...` | AI-generated images (`image_generation`) and rendered highlight films (`highlight_film`) | Stored separately from user originals |
| `exports/<space_id>/<archive_id>.<zip\|pdf\|mp4>` | Space archives and memory book exports | 7-day TTL |

## 3. Upload, Reliability & Orphan Recovery

- **Upload flow:** `POST /v1/media/presign` (authZ + MIME allowlist + per-kind size caps + quota check) → direct `PUT` to Neon Object Storage signed URL → `POST /v1/media/confirm` (verifies object existence & exact byte length, idempotent) → FFmpeg processing (`ready`/`failed`).
- **Orphan recovery:** Unconfirmed reservations do not count toward quota; server-side generated uploads (`image_generation`, `highlight_film`) delete the S3 object in an `except` block if PostgreSQL flush fails; `DELETE /v1/media/{id}` soft-deletes in PostgreSQL, releases quota, and deletes both original and derivative objects from Neon Object Storage.
